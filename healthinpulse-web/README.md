# 📌 Sobre o Projeto

O **HealthInPulse** é uma solução acadêmica desenvolvida na FIAP com foco em monitoramento inteligente de saúde em tempo real.

O projeto propõe o desenvolvimento de uma pulseira inteligente integrada a um dashboard web capaz de monitorar indicadores fisiológicos e gerar alertas preventivos.

# 🧠 Objetivo do Projeto

O projeto busca transformar o modelo tradicional de saúde reativa em um sistema preventivo baseado em dados em tempo real.

A ideia é permitir:

- monitoramento contínuo
- detecção de padrões anormais
- geração de alertas
- acompanhamento remoto
- integração futura com sensores IoT

# 🔧 Instalação Completa do Projeto

## 1️⃣ Instalar Programas Necessários

Antes de começar, instale:

- Node.js
- Git
- VSCode

---

## 2️⃣ Clonar o Repositório

Abra o terminal e execute:

```bash
git clone
```

---

## 3️⃣ Entrar na Pasta do Projeto

```bash
cd Healthinpulse/healthinpulse-web
```

---

## 4️⃣ Instalar Dependências

```bash
npm install
```
---

## 5️⃣ Instalar Biblioteca de Gráficos

```bash
npm install recharts
```

---

## 6️⃣ Rodar o Projeto

```bash
npm run dev
```

---

## 7️⃣ Abrir no Navegador

Acesse:

```txt
http://localhost:5173
```

---

# 🛠️ Caso o npm apresente erro no Windows

Abra o PowerShell como administrador e execute:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Depois confirme digitando:

```powershell
Y
```
